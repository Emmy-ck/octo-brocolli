## Step 1: Downloading Qbit

Visit this site: https://www.fosshub.com/qBittorrent.html

And click on the file shown in the image below. The download should start automatically.

![](img/0-qbit-download.png)

Your browser will indicate in the **top-right** the download progess. You can also press the keyboard shortcut **Ctrl + J** to open the downloads tab of your browser where you should see the downloading file.

Once the file has finished downloading, click on it to install it.

## Step 2: Setting Up Qbit

When you open Qbit for the first time, you'll be welcomed with the homescreen that looks like this

![](img/1-qbit-home.png)

<br>

Click on the **Search** tab and you'll see a screen like this. This is where our downloading journey begins

![](img/2-qbit-search.png)

<br>

There are a few **plugins** we need to download for Qbit before we can start using it to download things.

So click on the **Search plugins** button at the bottom-right of the Qbit window

This action will open the **Search plugins** window, unlike mine where I've installed a couple of plugins, yours will be empty.

![](img/3-qbit-search-plugins-window.png)

<br>

Next, we need to install a couple of plugins.

Click on the **link** shown above the **Check for updates** button.

![](img/3-qbit-search-plugins-window-plugins-link.png)

<br>

This action will redirect you to an online GitHub page where the plugins are available.

![](img/6-qbit-search-plugins-source-url.png)

<br>

Scrolling down the page you'll find a table containing the actual plugins we need.

![](img/7-qbit-search-plugins-source-url.png)

<br>

To install a plugin is fairly easy, on the **Download Links** column **right-click** on the link and select **Copy link address**.

![](img/7-qbit-search-plugins-copying-plugins-url.png)

<br>

![](img/8-qbit-search-plugins-copying-plugins-url.png)

<br>

Once the link has been copied, go back to Qbit and install the plugin by clicking the **Install a new one** button.

This action will open a pop-up asking you to select a plugin source.

Select **Web Link**

![](img/4-qbit-search-plugins-source.png)

<br>

The link you copied should be automatically filled into the URL field, but just in case it isn't, paste it in and select **Ok**

![](img/5-qbit-search-plugins-source-url.png)

<br>

And with that, you will have successfully added a plugin to Qbit.

Now just repeat the process of Copying the link from the GitHub page and pasting it in into Qbit to add the following plugins.

![](img/9-qbit-search-plugins.png)

<br>

![](img/10-qbit-search-plugins.png)

<br>

![](img/11-qbit-search-plugins.png)

<br>

![](img/12-qbit-search-plugins.png)

<br>

Your plugins window on Qbit should now have **5 new plugins** listed.

![](img/3-qbit-search-plugins-window.png)

## Step 3: Searching for courses on Qbit

We can finally get the show on the way and start searching for courses.

Close the **Search plugins** window and you should be back to the **Search** page of Qbit

![](img/2-qbit-search.png)

<br>

Try searching for something, let's say **100 days of code**.

You'll see a couple of results loaded as shown below.

![](img/searching/1-course-search.png)

<br>

Click on the **Seeders** column heading to organize the numbers from highest to lowest

![](img/searching/2-course-search-sorting-by-seeds.png)

<br>

## Step 4: Starting Downloads on Qbit

To download the right one, **double-click** on the one with the following properties

- ... The Complete Python Pro Bootcamp 2023
- Size: 20.12GB
- Seeders: 458
- Search engine: https://glodls.to

As shown in the screenshot above (highlighted in Blue).

Once **double-clicked**, you'll see the following window pop-up.

At the bottom-left, you'll see a loading bar with the text 'Retrieving metadata...' this just means that the contents of the file are being loaded.

![](img/searching/3-course-search-retrieving-metadata.png)

<br>

Once the metadata has been retrieved, you should see the content loaded on the **right-hand** half of the download window as shown below.

![](img/searching/4-course-search-content-loaded.png)

<br>

In order to start downloading, we should select where in our computer to store the download.

By default, it should show that it's going to the **Downloads** folder of your computer.

![](img/searching/5-course-download-location.png)

<br>

Add the following to the text shown in the field "..\Downloads\\**Courses**" this will create a folder called **Courses** inside your **Downloads** folder.

Press **Ok** to start the download.

![](img/searching/6-course-download-start.png)

<br>

The **download options** window will close automatically, then click on the **Transfers** tab (on the left side of the **Search** tab) to go to the transfers window.

![](img/searching/7-transfer-window.png)

<br>

You'll see the download as shown above and all you have to do is to wait for the download to complete...

Just take note of two things:

1. The **Download Speed** (yours might be faster or slower than mine)
2. The **ETA** when the download will be done

Once the course download is **100% Complete** let me know cause there's a step we'll have to take (we need to stop it from seeding)

You can go ahead and close Qbit (_Don't worry, the download will still continue in the background_), just **remember to occasionaly check-in on the download progress**

Btw if you open your file explorer and go to your **Downloads** folder, you should see a **Courses** folder and inside it, the downloading course files

![](img/searching/courses-folder.png)
